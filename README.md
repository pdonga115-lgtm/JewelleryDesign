# Jewellery Design Website

An ASP.NET Web Forms jewellery shopping website project.

## Project files
- ASP.NET Web Forms pages (`.aspx`)
- C# code-behind files (`.aspx.cs`)
- CSS and JavaScript assets
- SQL database script in `App_Data/JewelleryDB.sql`
- Visual Studio solution and project files

## Note
Open `JewelleryDesign.sln` in Visual Studio to work with the project. Configure the database connection in `Web.config` for your local environment before running the website.
